# 📊 IA CSV Converter

Un outil simple et intelligent pour transformer n'importe quel fichier non structuré (PDF, texte, JSON complexe) en un fichier CSV propre et organisé, optimisé par l'Intelligence Artificielle.

## 🚀 Description

Ce projet permet de simplifier la manipulation de données pour un usage personnel. Plutôt que de nettoyer manuellement des fichiers disparates, l'IA analyse le contenu, extrait les informations pertinentes et les structure dans un format tableau (CSV) prêt à l'emploi.

## ✨ Fonctionnalités

- **Multi-format :** Supporte l'entrée de fichiers `.txt`, `.pdf`, `.xlsx` et texte brut.
- **Extraction Intelligente :** Utilise l'IA pour identifier les colonnes (dates, montants, noms, etc.).
- **Nettoyage Automatique :** Normalisation des formats (ex: formats de date uniformisés).
- **Interface Intuitive :** Interface web simplifiée conçue avec **Streamlit**.
- **Export Facile :** Téléchargement instantané en format `.csv`.
